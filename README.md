# Astral Music — Canal Oficial de Actualizaciones (OTA)

Este repositorio aloja **únicamente** los paquetes APK compilados y sus notas de versión documentadas para las actualizaciones directas (*Over-The-Air*) desde la aplicación **Astral Music**.

> El código fuente principal no se publica aquí.

## Cómo actualizar sin cable USB
1. Abre **Astral Music** en tu teléfono.
2. Ve a **Ajustes → Actualizaciones OTA**.
3. Pulsa **Actualizar ahora** cuando haya una nueva versión disponible.
4. La aplicación descargará el APK oficial desde [Releases](https://github.com/ElGermanDBg/AstralMusic-Releases/releases) y lanzará el instalador del sistema.
